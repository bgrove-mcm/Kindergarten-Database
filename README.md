# Kindergarten Management Database

## Overview

This project is a relational database designed to manage information
for a kindergarten. The database organizes student, teacher, classroom,
health, lunch, and transportation information.

## Technologies

- MySQL
- SQL
- MySQL Workbench
- ER Diagram

## Features

- Student and teacher management
- Classroom assignments
- Student health and allergy information
- Lunch balance and reduced lunch tracking
- Transportation information
- Student enrollment analysis

## SQL Concepts Demonstrated

- SELECT statements
- WHERE and ORDER BY
- Aggregate functions
- INNER JOIN
- LEFT OUTER JOIN
- Subqueries
- UNION
- Views
- Stored functions
- Stored procedures

## Example Analysis

The database can be used to answer queries such as:

- How many students are enrolled in each classroom?
- Which students have allergies?
- How many students receive reduced lunch?
- Which teacher is assigned to a student?
- How many students are assigned to each teacher?
